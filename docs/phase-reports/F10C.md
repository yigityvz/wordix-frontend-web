# F10C — Quiz Start Screen

## Tamamlananlar

- Backend `StartQuizCommandValidator` kaynak kodu canlı Swagger'a ek olarak kontrol edildi; form seçenekleri gerçek destek matrisine göre sınırlandı.
- Quiz tipi olarak yalnızca `Test` ve `Writing` sunuluyor; domain enumunda bulunsa da validatorın reddettiği `Mixed` çalışan seçenek yapılmadı.
- Kaynak olarak yalnızca canonical `UserDictionary` ve `Deck` sunuluyor; validatorın reddettiği `DifficultItems`, `SystemRecommendations` ve `Mixed` kaynakları gösterilmiyor.
- İçerik modları `WordsOnly`, `PhrasesOnly`, `Mixed` ve `SentencesOnly` olarak eklendi; `SentencesOnly` yalnızca Writing quiz için seçilebilir.
- Soru sayısı backend validatorıyla aynı 1–20 aralığında tutuluyor.
- Backend desteği bulunmayan `difficulty` alanı UI ve request modeline eklenmedi.
- Deck kaynağında gerçek `GET /api/decks` collectionı yükleniyor ve canonical deck UUID seçilmeden start requesti gönderilmiyor.
- `includeSystemRecommendations` toggle'ı gerçek start request alanına bağlandı.
- Protected `/quizzes/start` lazy route'u, Quiz ve Deck feature providerlarıyla user shell altına eklendi.
- Quiz route'u oluşturulduktan sonra desktop/mobile user navigation'a gerçek Quiz bağlantısı açıldı.
- Start butonu yalnızca gerçek `POST /api/quizzes` facade/effect akışını çalıştırıyor; loading, validation, API error ve gerçek session success durumları eklendi.
- Figma/Make exportundaki 30 soru sınırı, difficulty alanı, unsupported source seçenekleri ve mock deck verileri aktarılmadı.
