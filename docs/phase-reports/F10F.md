# F10F — Recommended Item Save

## Tamamlananlar

- Sistem önerisi yanlış cevaplandığında backend answer responseundaki `canAddRecommendedItemToDictionary` ve `quizRecommendationItemId` alanlarıyla gerçek save yüzeyi eklendi.
- Save aksiyonu `POST /api/quizzes/recommendations/{quizRecommendationItemId}/save-to-dictionary` facade/effect akışına bağlandı.
- Backend uygunluk bayrağı veya recommendation UUID'si yoksa buton gösterilmiyor.
- Loading sırasında tekrar save ve soru/summary geçişi engellendi.
- Normalize backend hatası aynı yüzeyde gösteriliyor ve aynı gerçek endpoint için retry sağlanıyor.
- Başarılı response sonrası gerçek `userLearningItemId` ile dictionary detail bağlantısı gösteriliyor.
- Recommendation mutation state'i soru geçişlerinde temizlenerek başka soruya stale sonuç sızması engellendi.
- Backendin idempotent `wasAlreadySaved` / reactivation davranışı response mapper ve mevcut state akışında korunuyor; frontend fake dictionary kaydı üretmiyor.

## Backend sözleşmesi notu

Recommendation UUID ve save uygunluğu `SubmitQuizAnswerResponse` içinde bulunmaktadır; `QuizSummaryResponse` bu alanları taşımamaktadır. Bu nedenle save aksiyonu, gerçek kimliğin bulunduğu active quiz feedback ekranında sunulur. Summary refresh sonrasında kimlik varsayımı yapılmaz.
