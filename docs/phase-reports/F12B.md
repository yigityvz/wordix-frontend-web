# F12B - Admin Analytics UI ve Dashboard Duzeltmeleri

## Tamamlanan kapsam

- Backend API connection string MSSQL container sifresiyle uyumlu hale getirildi.
- WordixDb baglantisi ve gercek veritabani tablolari dogrulandi.
- User dashboard gercek learning summary ve difficult items endpointleriyle dolduruldu.
- Dashboard hero, dort canli metric karti, learning lifecycle, difficult items ve gercek route quick actionlari eklendi.
- Light, Dark ve System tercihini koruyan kompakt tema butonu uygulandi.
- Sidebar ve mobile navigation kisaltmalari gercek SVG ikonlarla degistirildi.
- Admin dashboard ve Top Lookups, Most Saved, Quiz Insights, Provider Stats ekranlari gercek admin endpointlerine baglandi.
- User ve admin shell ayrimi korundu; demo switcher veya user uygulamasina geri donus eklenmedi.

## Takip duzeltmeleri

- Sidebar altina Keycloak token gorunumunden uretilen guvenli kullanici karti ve gercek logout aksiyonu eklendi.
- Sidebar viewport boyunca sabitlendi; yalnizca ana icerik alani scroll olur.
- Shared card hostu blok seviyesine alindi.
- Dictionary, Lookup ve Dashboard kart araliklari artirildi.
- Lookup formunda dil secimi, alan etiketi, helper metni ve aksiyonlar arasindaki dikey bosluk artirildi.
- Profil karti gercek `/settings` route'una baglandi.
- Settings ekrani yalnizca desteklenen Light, Dark ve System tema tercihlerini sunar.
- Settings dahil ekran stilleri Tailwind utility classlari ve global `src/styles.css` tema tokenlariyla uygulanir; bos component CSS dosyasi uretilmez.
- Tema secimi mevcut ThemeFacade ve ThemeService uzerinden aninda uygulanir ve `wordix-theme` anahtariyla browserda saklanir.
- Notification, dil ve quiz preference alanlari backend destegi olmadigi icin eklenmedi.
