# F11A — Statistics API and State

## Tamamlananlar

- Canlı `http://localhost:5000/swagger/v1/swagger.json` sözleşmesi okunarak beş user-statistics endpointi doğrulandı.
- `GET /api/user-statistics/learning-summary` entegrasyonu eklendi.
- `GET /api/user-statistics/quizzes` için Swagger'daki tarih ve quiz filtreleri eklendi.
- `GET /api/user-statistics/difficult-items` için gerçek pagination, source, sort ve item/status filtreleri eklendi.
- `GET /api/user-statistics/decks` entegrasyonu eklendi.
- `GET /api/user-statistics/confidence-distribution` entegrasyonu eklendi.
- Request query alanları Swagger'daki PascalCase isimlerle üretiliyor; undefined/boş değerler gönderilmiyor.
- Bütün response DTO alanları canlı Swagger ile eşleştirildi.
- Nullable difficult-item, deck ve confidence collectionları mapper katmanında boş diziye normalize edildi.
- Her endpoint için bağımsız loading/data/error state, action, reducer ve selector akışı eklendi.
- Filter/pagination değişimlerinde önceki read requestini iptal eden `switchMap` effects eklendi.
- Componentlerin NgRx ayrıntısını bilmemesi için `StatisticsFacade` ve lazy feature provider eklendi.
- Ownership/user id parametresi hiçbir requeste eklenmedi.
