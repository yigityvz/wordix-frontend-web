# F10A — Quiz API ve Modeller

## Tamamlananlar

- Canlı Swagger üzerinden dört gerçek quiz endpointi ve bütün request/response alanları yeniden doğrulandı.
- `POST /api/quizzes` için start request/response transport ve normalize modelleri eklendi.
- `POST /api/quizzes/{quizSessionId}/answers` için answer requesti ile backend doğruluk/progress response modelleri eklendi.
- `GET /api/quizzes/{quizSessionId}/summary` için aggregate summary ve question breakdown modelleri eklendi.
- `POST /api/quizzes/recommendations/{quizRecommendationItemId}/save-to-dictionary` için gerçek recommendation save response modeli eklendi.
- Dört endpoint merkezi `ApiResponse<T>` unwrap ve environment API base URL standardıyla `QuizApiService` içine bağlandı.
- Nullable question/option/summary listelerini boş dizilere dönüştüren mapperlar eklendi.
- Frontend cevap doğruluğu hesaplamıyor; `isCorrect`, `answerResult`, doğru cevap ve progress değerleri backend responseundan değişmeden taşınıyor.
- Swagger requestinde bulunmayan `difficulty` alanı ve ownership alanları modellere eklenmedi.
