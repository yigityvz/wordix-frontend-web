# F11B — Statistics UI

## Tamamlananlar

- Protected `/statistics` route'u statistics lazy provider ve user shell altında eklendi.
- User desktop/mobile navigation listesine yalnızca çalışan Statistics bağlantısı eklendi.
- Route açılışında beş gerçek statistics endpointi bağımsız facade intentleriyle yükleniyor.
- Learning summary kartları saved items, accuracy, mastered/learned ve confidence aggregate değerlerini backendden gösteriyor.
- Quiz analytics paneli session, answer, correct/wrong, accuracy ve response-time aggregate değerlerini gösteriyor.
- Backend-supported 7/30/90 gün ve All/Test/Writing filtreleri gerçek `FromUtc`, `ToUtc`, `QuizType` queryleriyle çalışıyor.
- Confidence distribution harici chart kütüphanesi veya mock data olmadan, backend bucket/percentage değerleriyle erişilebilir bar görünümünde gösteriliyor.
- Difficult-items tablosu gerçek pagination, source ve sort filtreleriyle çalışıyor; satırlar gerçek dictionary detail route'una bağlı.
- Deck performance grid gerçek deck statistics collectionını gösteriyor; kartlar gerçek deck detail route'una bağlı.
- Her endpoint için bağımsız loading, hata ve gerçek retry yüzeyi eklendi.
- Statistics ekranından gerçek quiz setup route'una geçiş eklendi.
- Figma'daki fake trend ve study streak değerleri uygulanmadı; yalnızca backend sözleşmesindeki veriler gösterildi.
