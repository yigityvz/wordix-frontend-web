# F10B — Quiz NgRx State ve Facade

## Tamamlananlar

- Quiz session start, answer submit, summary load ve recommendation save operasyonları için birbirinden bağımsız lifecycle state alanları eklendi.
- Start actionı yeni session öncesinde önceki answer, summary ve recommendation sonuçlarını güvenli biçimde temizliyor.
- Backend answer sonuçları canonical `quizQuestionId` altında immutable sözlükte saklanıyor; frontend doğruluk hesabı yapmıyor.
- Session içindeki ilk cevapsız soruyu, cevaplanan unique soru sayısını ve bütün loading durumlarını türeten selectorlar eklendi.
- Dört gerçek quiz API operasyonunu yöneten effects eklendi; start/answer/recommendation tekrar submitleri `exhaustMap`, summary yenilemesi `switchMap` ile yönetiliyor.
- Normalize `ApiError` mesajları korunuyor; bilinmeyen hatalar için operasyona özel güvenli mesajlar kullanılıyor.
- Page ve componentlerin NgRx ayrıntısı bilmeden kullanacağı `QuizFacade` eklendi.
- State, effects, API service ve facade bağımlılıklarını ilerideki lazy quiz route'una kaydedecek `provideQuizFeature` providerı eklendi.
- Mock mutation, local doğruluk hesabı, difficulty alanı veya browser-close finalization davranışı eklenmedi.
