# F12A — Admin Analytics API and State

## Tamamlananlar

- Canlı Swagger sözleşmesi okunarak beş admin analytics endpointi doğrulandı.
- GET /api/admin/analytics/dashboard entegrasyonu eklendi.
- GET /api/admin/analytics/top-searches entegrasyonu eklendi.
- GET /api/admin/analytics/top-saved entegrasyonu eklendi.
- GET /api/admin/analytics/most-wrong entegrasyonu eklendi.
- GET /api/admin/analytics/provider-stats entegrasyonu eklendi.
- FromUtc, ToUtc ve Limit query alanları Swagger'daki PascalCase isimlerle üretiliyor; undefined değerler gönderilmiyor.
- Liste endpointlerinde backend varsayılanıyla uyumlu 20 limit kullanıldı; backend maksimum değeri 100 olarak doğrulandı.
- Response DTO alanları canlı Swagger ile eşleştirildi.
- Nullable top-searches, top-saved, most-wrong ve provider collectionları mapper katmanında boş diziye normalize edildi.
- Beş endpoint için birbirinden bağımsız loading/data/query/error state, action, reducer ve selector akışı eklendi.
- Son filtre isteğini esas alan switchMap effects ve merkezi ApiError mesaj aktarımı eklendi.
- Componentlerin NgRx ayrıntısını bilmemesi için AdminAnalyticsFacade ve lazy feature provider eklendi.
- User/owner id hiçbir requeste eklenmedi; bearer token mevcut auth interceptor akışında kalıyor.
- F12A kapsamında admin UI, route ve navigation değiştirilmedi.
